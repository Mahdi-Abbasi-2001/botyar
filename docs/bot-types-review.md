# بازبینی انواع ربات و امکانات تازه

این سند هر نوع ربات (بخش) را که ایجنت بات‌یار می‌سازد یک‌به‌یک بررسی می‌کند: امروز چه می‌کند، صاحب واقعی چنین کسب‌وکاری چه چیزی کم دارد، و چه چیزی اضافه شد. قاعده‌ی ثابت همه‌ی امکانات: موتور ربات قطعی است (بدون هوش مصنوعی در پاسخ به مشتری)، هر امکان تست خودکار دارد، و پیش‌فرض‌ها رفتار ربات‌های منتشرشده و تست‌های ذخیره‌شده‌ی آن‌ها را تغییر نمی‌دهند.

علامت‌ها: ✅ ساخته شد · ⏳ بعداً · ✗ عمداً نه (با دلیل)

## وقتی چیزی پشتیبانی نمی‌شود

هیچ مجموعه‌ای از امکانات همه‌ی درخواست‌ها را پوشش نمی‌دهد. رفتار ایجنت در این حالت تغییر کرد:
- جزئیاتی که ساختنی نیست دیگر ساخت ربات را متوقف نمی‌کند و ایجنت درباره‌اش سؤال بی‌جواب نمی‌پرسد؛ نزدیک‌ترین ربات کارا ساخته می‌شود.
- آنچه کنار گذاشته شد در پیام پایانی با عنوان «هنوز پشتیبانی نمی‌شود» نوشته می‌شود و با یک دکمه برای تیم بات‌یار درخواست (تیکت) ثبت می‌شود.
- اگر طراحی سه بار نامعتبر شود، ساخت با پیام روشن و پیشنهاد ثبت درخواست تمام می‌شود؛ هرگز بی‌صدا متوقف نمی‌شود.

| امکان | چرا | وضعیت |
|---|---|---|
| به خاطر سپردن نام و شماره‌ی مشتری («با همین مشخصات ادامه می‌دهید؟») | مشتری دائمی هر بار همه‌چیز را از نو تایپ نکند | ✅ |
| خلاصه‌ی روزانه برای مدیر، ساعت ۸ صبح (نوبت‌های امروز، سفارش‌های باز، پیام و سؤال بی‌پاسخ) | مدیر بدون باز کردن پنل روزش را برنامه‌ریزی کند؛ قابل خاموش کردن | ✅ |
| اعلان برای هر همکار («/staff کد»: نوبت‌های تازه و لغوشده‌ی خودش) | سالن و کلینیک با چند همکار | ✅ |
| اطلاعیه برای یک گروه (یک بخش ربات، شرکت‌کنندگان یک جلسه، مشتریان اخیر) | «کلاس فردا لغو شد» نباید به همه برسد؛ پیام جلسه حتی به کسانی که /stop زده‌اند می‌رسد | ✅ |

## سؤال‌ها (مشترک فرم، نوبت‌دهی و سفارش)

امروز: متن، شماره‌ی موبایل (با بررسی قالب)، عدد، انتخاب از گزینه‌ها؛ سؤال اختیاری.

| امکان | چرا | وضعیت |
|---|---|---|
| دکمه‌ی «رد کردن» برای سؤال اختیاری | **ایراد**: پیام‌رسان پیام خالی نمی‌فرستد، پس سؤال اختیاری عملاً اجباری بود | ✅ |
| ایمیل (با بررسی قالب) | فرم‌های ثبت‌نام دوره و همکاری | ✅ |
| کد ملی (با رقم کنترل) | ثبت‌نام آموزشی، بیمه، کلینیک | ✅ |
| تاریخ شمسی (مثل ۱۴۰۳/۰۸/۱۵) | تاریخ تولد، تاریخ مراسم، تاریخ تحویل | ✅ |
| چندانتخابی (چند گزینه + «تمام») | علاقه‌مندی‌ها، روزهای آزاد، خدمات موردنیاز | ✅ |
| حداقل و حداکثر برای عدد | سن ۱۸ تا ۶۰، تعداد نفرات ۱ تا ۱۰ | ✅ |
| موقعیت روی نقشه برای نشانی (یا نوشتن نشانی) | نشانی اشتباه کمتر؛ مدیر لینک نقشه می‌گیرد | ✅ |
| بارگذاری عکس یا فایل از مشتری | | ✅ در فرم‌ها (سؤال «فایل») و رسید کارت‌به‌کارت |

| سقف نوبت فعال برای هر مشتری | یک نفر همه‌ی سانس‌ها را نگیرد | ✅ |
| تعداد نفرات در یک رزرو | رستوران، تور، کلاس خانوادگی | ✅ |
| بیعانه‌ی آنلاین (نوبت تا پرداخت نگه داشته می‌شود؛ پرداخت‌نشده پس از ۱۵ دقیقه آزاد می‌شود) | جدی بودن رزرو؛ استرداد دستی با مدیر | ✅ |
| تأیید حضور از روی یادآوری («می‌آیم / نمی‌توانم بیایم») | بهترین درمان غیبت؛ جای خالی‌شده به لیست انتظار می‌رسد | ✅ |
| ساعت کاری جدا برای هر همکار | همکاران زمان‌بندی یکسان ندارند | ✅ |
| کدام همکار کدام خدمت را انجام می‌دهد | ترکیب ناممکن رزرو نشود | ✅ |
| علامت «حاضر نشد» و بستن رزرو آنلاین پس از N غیبت | کلینیک و سالن | ✅ |

## فروشگاه و منو (سفارش)

امروز: منوی کوتاه یا جدول محصولات، دسته‌بندی، جست‌وجو، گزینه‌ها، موجودی، سبد، حداقل سفارش، کد تخفیف، هزینه‌ی ارسال و مناطق ارسال، پرداخت آنلاین و کارت‌به‌کارت، عکس محصول، زمان تحویل، لغو، وضعیت سفارش.

| امکان | چرا | وضعیت |
|---|---|---|
| مناطق ارسال با هزینه‌ی جدا (تهران / سایر شهرها / تحویل حضوری) | رایج‌ترین درخواست فروشگاه‌های اینترنتی؛ قبلاً ساخت ربات را متوقف می‌کرد | ✅ |
| قیمت متفاوت برای گزینه (سایز XL ۵۰ هزار بیشتر) | لباس، پیتزا، قهوه با شیر گیاهی | ✅ |
| دیدن و ویرایش سبد (حذف قلم) | استاندارد هر فروشگاه؛ امروز اشتباه فقط با شروع دوباره درست می‌شد | ✅ |
| نمایش توضیح محصول | توضیح در جدول ذخیره می‌شد ولی به مشتری نشان داده نمی‌شد | ✅ |
| انتخاب تعداد برای منوی کوتاه | دو لاته = دو بار افزودن | ✅ |
| ساعت سفارش‌گیری (بیرون از آن، پیام «بسته‌ایم») | کافه و رستوران | ✅ |
| کارت‌به‌کارت (نمایش کارت، دریافت شماره‌ی پیگیری یا عکس رسید، تأیید مدیر در «ثبت‌ها») | رایج‌ترین روش پرداخت فروشگاه‌های کوچک | ✅ |
| عکس محصول (بارگذاری در «محصولات») | لباس و کفش بدون عکس فروش نمی‌رود | ✅ |
| «موجود شد خبرم کن» | ناموجود را به فروش تبدیل می‌کند | ✅ |
| هشدار کم شدن موجودی به مدیر | پیش از تمام شدن، سفارش بدهید | ✅ |
| تکرار سفارش قبلی (با قیمت امروز) | کافه و مشتری ثابت | ✅ |
| انتخاب زمان تحویل یا دریافت، با سقف سفارش در هر بازه | رستوران و شیرینی‌فروشی | ✅ |
